# 📦 LogiTrans — Integrated Supply Chain & Logistics Landing Page

LogiTrans adalah proyek *landing page* modern untuk perusahaan logistik skala domestik dan korporat. Dibuat dengan fokus pada performa tinggi, tampilan premium, dan pengalaman pengguna yang interaktif.

## 🚀 Fitur Utama
* **Responsive Hero Section:** Tampilan adaptif yang memikat di layar desktop maupun smartphone menggunakan aset gambar multimodal lokal.
* **Widget Interaktif (Cek Resi & Ongkir):** Fitur simulasi dinamis dengan sistem tab manajemen.
* **Auto-Hide Form Logic:** Form kalkulasi ongkir otomatis menyembunyikan inputan utama setelah tombol diklik untuk memberikan ruang baca yang bersih bagi pengguna (*state management*).
* **Corporate Lead Generation Form:** Formulir kontak yang dirancang khusus untuk kebutuhan penawaran bisnis (B2B).

## 🛠️ Teknologi yang Digunakan
* **HTML5** - Struktur semantik website.
* **Tailwind CSS v4 (CDN)** - Framework CSS modern untuk penyusunan tata letak (grid/flexbox) dan desain premium.
* **Vanilla JavaScript** - Manipulasi DOM murni untuk logika interaksi tab, pelacakan, dan reset form tanpa library eksternal yang berat.
